# Guia para as páginas do Orion 2.0 (client)

Stack: Vite + React 18 + TypeScript (strict off) + react-router v6. Sem Tailwind. Estilos globais em `src/styles.css` (tokens em `:root`, classes utilitárias: `.card .kpi .btn .btn.p .btn.g .btn.sm .btn.icon .inp .sel .ta .field .row .grid .g2 .g3 .pill.ok|warn|crit|info|win|dim .tag .meter .av .seg .tabs .modal .empty .mono .muted .dim table/th/td .code-block .chips .chip`). Se precisar de CSS específico da página, coloque num arquivo `src/pages/<Page>.css` importado pela página, usando SEMPRE as variáveis de cor (`var(--green)`, `var(--panel)`, etc). Nunca hexcodes soltos.

Componentes em `src/components/ui.tsx`: `useToast().toast(text, isError?)`, `Modal({title,onClose,footer,size:'lg'})`, `Toggle({on,onChange,label})`, `Pill({kind})`, `Empty({title,action})`, `Spinner`, `Segmented({value,onChange,options})`, `Field({label,hint})`, `Avatar({name,size})`, `Icon({name,size})` (nomes: dashboard chat funnel bolt send template users phone settings x plus check refresh trash search play pause copy upload image video mic file clock reply branch tag arrow stop list button var dots external filter download more eye alert zap log logout), `ConfirmButton({onConfirm})` (2 cliques para confirmar), `CopyButton({text})`.

API: `src/lib/api.ts` → `api.get/post/put/del(url, body)` (prefixo `/api` automático, lança `ApiError` com `.message`), `api.upload(url, file, extra)`, `subscribe({message,status,templates,run})` para SSE, formatadores `fmtMoney fmtNum fmtPct fmtPhone fmtTime fmtDate fmtDateTime fmtRel initials fmtDuration fmtWindow`.

Layout: cada página renderiza `<main className="main">` (ou `main full` para páginas de tela cheia como inbox/builder) com `<div className="top"><div><h1>Título</h1><div className="sub">descrição</div></div><div className="tools">…</div></div>`. Texto do painel em português do Brasil, tom direto. Números tabulares com `.mono`. Estados vazios com `<Empty>` explicando o que fazer. Tudo responsivo o suficiente para 1100px+.

## Endpoints (todos sob /api, autenticados por cookie)

Funis: GET /funnels → [{id,name,description,status(draft|published|archived),version,runs,conversions,replies,updated_at}] · POST /funnels {name} · GET /funnels/:id → {…,nodes,edges,viewport,node_stats[{current_node,status,c}],errors[]} · PUT /funnels/:id {name,description,nodes,edges,viewport} · POST /funnels/:id/publish (422 {errors[]}) · POST /funnels/:id/duplicate · DELETE /funnels/:id · POST /funnels/:id/test {phone,name?} · GET /funnels/:id/runs
Formato dos nós (React Flow): {id,type,position:{x,y},data:{label?,…}}; edges {id,source,target,sourceHandle?}. Tipos e data:
  trigger {label} — único, sem entrada. template {template_id, values:{"1":"{{primeiro_nome}}"}, header_media_id?} · text {text, preview_url?} · buttons {body,header?,footer?,buttons:[{id,title}],timeout_seconds?} saídas: sourceHandle = id de cada botão + 'default' (sem match) · list {body,header?,footer?,buttonText,sections:[{title,rows:[{id,title,description?}]}],timeout_seconds?} saídas: id de cada row + 'default' · image|video|audio|document {media_id, caption?, filename?} · delay {seconds} · wait_reply {timeout_seconds, save_as} saídas 'reply' | 'timeout' · condition {variable, op(eq|neq|contains|not_contains|starts|gt|lt|exists|empty|regex), value} saídas 'yes' | 'no' · set_var {key,value,persist?} · tag {tag,remove?} · goto_funnel {funnel_id} · end {outcome?}.
Regra da Meta: fora da janela de 24h só template. O validador exige que o primeiro bloco após o gatilho seja `template` (ou condition/set_var/tag/delay antes dele). Visualização única não existe na Cloud API.
